# Country Club Resorts Balakot - Landing Page

A professional, responsive landing page for Country Club Resorts Balakot built with Next.js 14, React, and Tailwind CSS.

## Features

Modern Design
- Clean, contemporary aesthetics
- Smooth scrolling navigation
- Responsive across all devices

Key Sections
- Hero: Eye-catching header with CTA button
- Features: Showcase of Riverside Cottages, Hand-Laid Stone Architecture, and Hot Air Balloon Experience
- About: Company mission and values
- Contact & Booking: Functional booking form with inquiry details

Fully Responsive
- Mobile-first design approach
- Optimized for tablets and desktop
- Touch-friendly navigation

Technology Stack
- Next.js 14 with App Router
- React 18
- Tailwind CSS
- Lucide-react Icons
- TypeScript

## Getting Started

Prerequisites
- Node.js 18+
- npm or yarn

Installation

1. Clone the repository
2. Install dependencies: npm install
3. Run the development server: npm run dev
4. Open http://localhost:3000 in your browser

## Project Structure

app/
- layout.tsx: Root layout
- page.tsx: Main page
- globals.css: Global styles

components/
- Navigation.tsx: Header navigation
- Footer.tsx: Footer component
- sections/
  - Hero.tsx: Hero section
  - Features.tsx: Features showcase
  - About.tsx: About section
  - Contact.tsx: Contact & booking form

## Customization

Update Colors: Edit Tailwind color values in components
Replace Images: Update image URLs in Hero and About sections
Update Contact: Modify contact details in Contact section
Form Integration: Connect booking form to backend API

## Deployment

Deploy to Vercel: npm run build && vercel deploy
